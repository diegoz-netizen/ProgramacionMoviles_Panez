# Registro de Notas - Laboratorio 03 (Semana 3)

Aplicación Android en Kotlin y Jetpack Compose para calcular el promedio ponderado de cuatro cursos utilizando componentes de interfaz interactivos (`Slider`, `Switch`, `Checkbox`).

## Casos de Prueba Verificados

| Notas (F, POO, M, BD) | Redondear | Prom. Ponderado | Prom. Final | Observación |
| :--- | :---: | :---: | :---: | :--- |
| 15, 13, 16, 14 | **ON** | 14.55 | 15 | APROBADO |
| 12, 10, 11, 9 | **OFF** | 10.45 | 10.45 | EN RECUPERACIÓN |
| 18, 17, 19, 18 | **ON** | 18.05 | 18 | EXCELENTE |
| 8, 9, 7, 10 | **OFF** | 8.45 | 8.45 | DESAPROBADO |
